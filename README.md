#         UKITAKE

This is a simple tool to help if you're investigating files and are too lazy to type a lot of commands. The tool can search single or multiple files by name, return information related to file, search files by contend, and it can search by SHA1 hash. The script is written in bash

# How to use it

1. Copy the code and save it as "ukitake.sh"
2. On your terminal, run the following (replace /path/to/ukitake.sh with the actual path):
   ```bash
   chmod +x /path/to/ukitake.sh
   ```
3. Run the file:
   ```bash
   /path/to/ukitake.sh
   ```
4. Select the task you want to perform from the displayed menu, then follow the prompts for any required arguments.
